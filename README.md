# 阅卷助手：用 DeepSeek 批改解答题

一个在你自己电脑上运行的小网页平台。每次考试的答题纸可以不一样：

- **考前**：上传试卷、参考答案（答案可选）。程序按题号位置把试卷和答案切成一道一道的题，每道题单独交给 DeepSeek 录入，再和原文自动核对。没有参考答案时，选择题、填空题由 DeepSeek **独立做两遍**（两遍不一样的标红请你核对），解答题由 DeepSeek 写参考答案和评分细则，你审核修改后再用。没有试卷文件，写一下“1-8 单选 5分”这样的题目结构也行。
- **答题纸**：考试用学校统一的答题纸，程序自动识别题框并标好题号和分值；周测、作业可以按题目**直接生成答题纸**（带定位点、二维码和涂学号的格子，打印或复印就能用，扫描后不用识别版面；解答题方框的高度可以在图上拖动调整）。
- **考后**：上传扫描件。程序自动对齐（歪斜、倒放、缩放都可以）→ 裁出每道解答题 → DeepSeek 识别手写 → 按评分细则逐小问给分 → 你在复核页面确认或改分 → 导出成绩表，以及写好分数的答题纸图片。

学生靠答题纸上**涂的学号**认出来，配合“班级名单”自动对上姓名，还能列出谁没交。

分三种类型：**考试**（月考、期中、期末）和**周测**按分值打分；**平时作业不打分**，每题只判“对 / 半对 / 错”，写出错在哪、怎么订正（见下面“平时作业”）。

三种题都批：**选择题**按涂卡识别（不调用模型）；**填空题**由 DeepSeek 识别手写后判对错，写法不同但等价的算对；**解答题**按评分细则逐小问给分。每道题的分值按试卷的大题说明逐题读出（例如“1–6 题每题 4 分，7–12 题每题 5 分”），页面上可以改。

## 安装和启动

需要 Python 3.9 或更高版本（Mac 自带的 `python3` 就可以）。

```bash
cd autograde
python3 -m venv .venv
source .venv/bin/activate          # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt    # 国内可加 -i https://pypi.tuna.tsinghua.edu.cn/simple
python run.py
```

浏览器会自动打开 http://127.0.0.1:8000 。先到右上角“设置”里填 DeepSeek 的 API Key（在 platform.deepseek.com 创建），也可以用环境变量 `DEEPSEEK_API_KEY`。

所有数据（上传的文件、批改结果、设置）都在 `data/` 文件夹里，删掉就清空。

## 使用流程

网页上每场考试分 4 步：

1. **题目与评分细则**：新建时先选类型（考试 / 周测 / 平时作业，之后也可以在右上角改）。上传试卷让 AI 录入，或者“按题号快速添加”。每道题左边是试卷和答案的原图截图，右边是录入的文字，对照着看。题目全文包括所有小问；参考答案原样保留步骤后面的“……X分”，这就是评分标准（多数答案是累计分，程序会自动判断并告诉给分模型）。自动核对发现问题的题会标“待核对”，改好后点“确认无误”。AI 生成的答案同样要确认。
   选择题和填空题在页面最上面的表格里：每题的分值和参考答案都可以直接改（选择题写字母，多选写在一起如 BD；填空题写 LaTeX）。没有答案的，建考试时默认让 AI 做（也可以点表格上方的“让 AI 做”）：每道题**独立做两遍**，两遍一样的标“AI”，不一样的整行标红并写出两个答案，请你核对后点“确认”（两遍一样的可以“确认两遍一致的 N 道”一次确认）。还没确认的可以“AI 重做”；改过的答案算老师填的。
2. **答题纸版面**：按题目生成答题纸（见下面“生成答题纸”），或者上传现成的空白答题纸让程序识别。红框是要批改的解答题。点一个框可以改题号、题型、分值；漏掉的作答区域用“画一个新区域”补上。一道题写在两个框里时，两个框都填这个题号。填空题的每条横线、选择题的每组选项框会用绿色细框标出来，题号不对可以在右边直接改。
3. **上传扫描件**：一次上传整个班的扫描件（多页 PDF、JPG、PNG、TIFF 都行），按扫描顺序即可。扫描仪把一整叠答题纸扫成的一个大 PDF（一两百页、几百 MB）可以直接传，程序一页一页地处理，不会占满内存；空白页自动跳过，缺页的答卷会标出来（见下面“扫描和答题纸”）。
4. **复核与成绩**（平时作业见下面）：左边是学生列表，黄色是建议复核的题。列表上面可以搜学生（姓名、学号、班级都行，拼音全拼或首字母也行，比如 `zs` 找张三；按 `/` 直接跳到搜索框），也可以按学号、姓名、总分排序。有名单时，上面会列出名单里还没有答卷的人。右边是裁出来的作答图、AI 给分和理由、手写识别结果。
   - “选择题”“填空题”两个标签页是表格：每题的作答截图、识别结果、参考答案、对错。选择题识别错了，点学生实际涂的选项，分数自动重算；填空题点“对/错”直接判，识别错了点“改识别”。
   - 点打分条上的数字直接改分；`Enter` 确认 AI 分数；`↑` `↓` 换学生，`←` `→` 换题。
   - 识别错了可以“修改转写”，再让 AI 按改过的内容重新给分。
   - “导出成绩表（CSV）”用 Excel 直接打开；“下载批改后的答题纸”是写好红字分数的图片。

## 生成答题纸

在“答题纸版面”里点“生成答题纸”，程序按第 1 步的题目排版：

- **选择题**是涂卡格子（每 5 题一组，多选题会注明），**填空题**是带题号的横线，**解答题**是方框，方框高度按分值给（12 分约 11 厘米，可以选紧凑、标准、宽松；平时作业不印分值，按小问数给），一栏放不下就接到下一栏，标“（续）”。**觉得哪道题的地方不够或太多，直接在图上拖方框下边的红色把手**，松手后自动重新排版、重新生成 PDF；也可以点开方框在右边填高度（毫米），“恢复自动”取消。题序和试卷一致（先填空后选择的试卷也照样排）。
- 纸张：**A4 竖版**（平时作业）或 **A3 横版两栏**（整套试卷）。A4 超过 2 页时会提示改用 A3。A3 每一栏是一页，页码印在每栏底下：正面左栏第 1 页、右栏第 2 页，反面左栏第 3 页、右栏第 4 页。
- 第 1 页有姓名、班级和**涂学号的格子**（位数可以设，有名单时默认按名单里学号的位数；填 0 就不印格子，由 AI 读手写姓名）。
- 每页四角和边上印“回”字定位点，右上角有**二维码**，写着是哪次考试、第几页、答题纸版本。
- 生成时就知道每个格子、每条横线、每个方框的确切位置，直接当作版面，**不用再识别**，选择题涂卡和学号涂卡都按印刷位置读。

生成后点“下载答题纸 PDF”打印。**打印时选“实际大小”，不要“缩放到页面”**；两页的双面打印。

### 学生怎么认：涂学号，还是二维码？

推荐**涂学号 + 写姓名**，二维码只标“哪次考试、第几页”：

- 涂学号的答题纸**每个学生都一样**，打一份原稿就能在复印机上复印全班，平时作业最省事。学号用和选择题一样的涂卡识别，不调用模型；有名单就自动对上姓名。
- 二维码（每份都一样）让程序认出每页是哪次考试、正面还是反面。一叠里**混进了别的作业的答题纸**会被挑出来，单独列在上传情况里，不会算进这次的成绩。
- 正式考试按座位发卷时，可以选**“每人一份 PDF”**：按名单给每个学生印一份，姓名、班级印好，学号格子预先涂好，二维码里也带着学号。读的方法完全一样，学生不用再涂学号。
- 学号没涂、涂了两个数字、涂得太浅的，会标“学号待核对”；这时程序会让 DeepSeek 读一下手写的姓名，在名单里找到这个人（请确认）。涂成了别人的学号，两份答卷都会标“重号”。在复核页上改好姓名和学号点“保存”即可。

题目改了（题号、题型、分值、选项数）之后要重新生成，页面上会提醒；**重新生成之前印的答题纸和新版面对不上**，扫描时会提示“旧版本”。

## 班级名单

右上角“班级名单”里导入：在 Excel 里选中“学号、姓名”两列复制，粘贴进来就行；也可以上传 `.xlsx`、`.csv`、`.txt`。第一行是表头时按“学号/考号/序号”“姓名”“班级”找列，有“班级”一列的会按班级分开存。名单只存在这台电脑的 `data/rosters.json` 里。

- 批改时按涂的学号在名单里找人；一次考试默认在全部名单里找（只认唯一匹配），也可以在复核页“对照名单”里指定班级（几个班学号有重复时要指定）。
- 名单导入或修改后，已经批过的答卷会自动重新对一遍（老师手动改过的不动）。
- 成绩表（CSV）最后会列出名单里没有答卷的人，备注“没有答卷”。

## 平时作业：不打分，只判对错

新建时类型选“平时作业”（已有的考试也可以在右上角改）：

- **不打分**：题目页不显示分值；生成的答题纸不印分值，解答题方框按小问数给高度。
- **每道题判“对 / 半对 / 错”**：选择题、填空题按答案判对错（多选题没选全算半对）；解答题由 DeepSeek 看手写过程判断，写出**错在哪**（第一个出错的地方和原因）和给学生的**订正提示**，有小问的逐个判。“半对”是思路对但有计算错误、过程不完整，或者几个小问有对有错。
- **答案可以不传**：上传作业的题目（PDF、拍照都行）就够了。选择、填空题 AI 先做两遍（见上），解答题没有参考答案时，AI 批改前自己先做一遍再判。题目和答案都没有的解答题，AI 只能看学生的过程判断，会提醒你。
- **复核页**：每题是“✓ 对 / ½ 半对 / ✗ 错”三个按钮，点一下就改判；学生列表显示“对 6.5/8”（半对算半题），可以按做对的多少排序；上面是每题对、半对、错的人数和选择、填空的正确率。
- **成绩表**每题写“对 / 半对 / 错”，最后是“做对题数”；批改后的答题纸上打 √、半对号、×，错的题旁边写一句错在哪。
- 在“打分”（考试、周测）和“不打分”（作业）之间改类型时，已经批过的答卷会自动按新的方式重新批一遍（老师改过的分会清掉，因为尺度不一样了；判对错的结果有缓存，改回来不再花钱）。考试和周测之间改不用重批。

没有试卷文件时，新建时在“题目结构”里写，或者在第 1 步“按题号快速添加”，每行一段（作业不用写分值）：

```
1-8 单选 5分
9-11 多选 6分
12-14 填空 5分
15 解答 13分 2问
16-17 解答 15分
```

然后在表格里填选择、填空的答案（没有题目内容 AI 没法做），解答题填参考答案（或者上传题目照片让 AI 做），再生成答题纸打印。

## 试卷和答案怎么录入的

- **数字版 PDF（Word/WPS 导出，推荐）**：程序先用 PDF 里的文字找到每道题的题号位置，把每道题（跨页的也拼好）单独裁成图，一次只把一道题交给 DeepSeek 录入。模型看不到别的题，就不会把别的题的内容混进来。录完后用 PDF 里的汉字逐题核对，多出来或漏掉的内容会列出来。
  - 分值直接从文字里读：“（本题满分15分…第(1)小题满分6分…）”、大题说明、答案里的“……6 分”，三处互相核对，对不上会提示。
  - 试卷后面附了答案（同一个 PDF）也可以，会在“参考答案”标题处自动分开。
  - 空白页、页眉页脚会自动跳过。
- **扫描件、照片**：没有文字可以核对，整份一次交给 DeepSeek 录入（不再一页一页地录，避免空白页、跨页出错）。请对照原图检查。
- **答题纸**：如果是数字版 PDF（像“18(15分)”这样的字是可以选中的文字），题号和分值直接从文字读出，不调用模型；扫描的答题纸才让 DeepSeek 看图识别。
- 改了题目或答案之后，在“上传扫描件”里点“按最新的评分细则重新给分”。
- 用旧版本建过的考试：打开考试，在“补充上传试卷或参考答案”里点“用已上传的文件重新录入”，题目和答案会按新的方式重新录一遍。

## 选择题和填空题怎么批的

- **选择题**：在答题纸模板上找出每道题的选项框（[A][B][C][D]、圆圈、方框都可以），按涂黑程度识别，不调用模型。没涂、涂了多个、涂得很浅或擦过的会标“待复核”。多选题（参考答案是多个字母）没选全时怎么给分，在“设置”里选：按比例（新高考规则）、不给分或固定几分。
- **填空题**：每条横线单独截图，一张卷子的所有填空拼成一两张图，一次交给 DeepSeek 识别。没写的空直接判 0 分，不调用模型。识别结果和参考答案写法一致的直接判对；不一致的再让模型判断是否等价，例如 √5 与 5^(1/2)、1+√10 与 √10+1、[2,4] 与 2≤ω≤4 都算对；题目横线后印着 rad 却写 90° 算错。默认整题判对错，不给部分分。要求必须化简到最简形式的，在“设置”里勾选。
- 每题的判分说明（如“写成小数也算对”）可以填在题目表格里，模型判断时会参考。
- 涂卡请用 2B 铅笔涂满；填空请用黑色笔写在横线上方。
- 成绩表里有每题分数、选择/填空/解答小计和总分；批改后的答题纸上，每题打 √ 或 ×，每块区域写小计。

## 关于准确率（请先看）

AI 给分是初评，适合“AI 先批、老师复核”，不建议不看就直接用。建议这样开始：

- **先拿一次已经人工批过的卷子试跑**，比如你发的这张样张（老师给了第15、16、17题 11、10、11 分），对比 AI 的分数，调整评分细则的写法。
- 正式使用时在“设置”里把“每道题独立批改几次”设为 2（双评），两次分差超过阈值的自动进“待复核”。
- 字迹识别清晰度低、模型自己没把握、给分超出范围、两次评分差太多的题，都会标“待复核”。
- 给分模型可以选 `deepseek-flash`（同时看原图核对识别结果，默认）或 `deepseek-v4-pro`（推理更强，但不支持图片，只看转写文字）。两种都值得用已批过的卷子比较一下。

## 扫描和答题纸

- 扫描 200–300 dpi，灰度或彩色。不要用纯黑白（二值）模式，浅的字迹容易丢。
- 学生用黑色笔。老师的红笔痕迹会被自动去掉（红色印刷的答题纸会自动识别，不去红）。
- 双面答题纸正反面都扫；建考试时选“每份答题纸扫描后几张图”。
- 答题纸上的作答区域最好是封闭的方框（绝大多数答题卡都是）。有“回”字形或实心方块定位点更准；没有也能用，会改用图像特征对齐。
- 没有空白答题纸时，用一份学生答题纸识别版面也可以。

### 用手机拍照代替扫描

没有扫描仪时，用手机拍也可以（周测、作业常这样）：

- **整张答题纸都拍进画面**，四个角和边上的黑方块都要拍到；尽量正对着拍、纸放平、光线均匀，不要有手指、阴影挡住。
- 拍得有点斜、纸有点弯（中间鼓起、边上翘）没关系：程序先按黑方块对齐，再按答题纸上印的框线、横线把纸面“拉平”，涂卡和学号照样能读、裁出来的作答图是正的。
- 每张照片一页，按顺序上传：JPG、PNG 都行；iPhone 的 HEIC 照片要装 `pillow-heif`（`requirements.txt` 里已经有了）；也可以在 Mac 上把几张照片导出成一个 PDF 再传。
- 照片比扫描件慢一些（每页多两三秒）。实在对不上的页，会在“最近一次上传”里写明是哪一页、为什么，按顺序归到一份答卷里请你人工批改。

上传之后，“上传扫描件”和“复核与成绩”页面最上面都会列出这次上传的情况（几页、分成几份、跳过了哪些页、为什么）；一份答卷都没分出来时会直接停在上传页告诉你原因。

### 一整叠扫成一个大 PDF

- **直接上传就行**。程序一次只把一页放进内存（读一页、对齐、裁切、存盘，再读下一页），一两百页、几百 MB 的 PDF 也只占几百 MB 内存。上传时按钮上显示进度，处理时进度条上显示第几页、已经分出几份、大概还要多久。
- 实测（2 核的云主机）：149 页、342 MB 的 A3 彩色扫描 PDF，上传 2 秒，对齐、分组、裁切约 3.5 分钟，服务进程内存峰值约 700 MB。之后调用模型批改的时间取决于 DeepSeek 的速度和并发数（见下）。
- **用双面扫描**，让每份答卷的各页挨在一起（第 1 份正面、第 1 份反面、第 2 份正面……）。程序按每一页认出它是答题纸的第几页来分组，所以个别页倒放、缺页都能分对。
- **关掉扫描仪的“跳过空白页”**。学生一个字没写的反面，印刷内容很少，可能被扫描仪当成空白页丢掉，这份答卷就会缺页。
- 上传完成后，复核页最上面会列出这次上传的情况：几页、分成几份、跳过了哪些空白页、哪几份缺第几页、哪几页没能和答题纸对上。页数是奇数（比如两页一份却扫出 149 页）通常就是有一份缺了一页，看这里就知道是哪一份。
- 缺页的答卷在学生列表里标“缺反面”（几张纸的说“缺第 2 张正面”），那一面上的题不批改。找到原卷补扫（只扫缺的那一面也行）上传后，打开这份答卷点“合并”把补扫的页并进来；学生那一面确实没写的，直接给 0 分。扫错、重复扫的答卷可以“删除这份”（原始扫描件不删）。
- 用灰度、200–300 dpi 扫，文件小很多，上传也更快。
- 一次批几十上百份时，在“设置”里把“同时进行的请求数”调到 16–32 会快很多（默认 16；DeepSeek 每个账号 deepseek-flash 的并发上限是 2500）。

## 费用

以 `deepseek-flash` 为例：一份答卷 3 道解答题、双评，大约用 3–4 万输入 token、2–3 万输出 token（含思考）。按 DeepSeek 官网 2026 年 10 月的价格，一个 50 人的班大约 2 美元左右，错峰时段减半；同一道题的题干和评分细则会命中缓存，实际更低。以官网价格页为准，网页上会显示每场考试累计的用量。

选择题不调用模型；填空题每份答卷多两次调用（拼图识别一次、判断等价一次，写法完全一致的不用判），费用增加很少。

同样的请求会缓存在本地，重复点“重新给分”不会重复收费；改了评分细则才会重新调用。

## 接入你自己的平台

后端是普通的 HTTP 接口（FastAPI），你的平台可以直接调用，自带网页只是其中一个前端。运行后打开 http://127.0.0.1:8000/docs 可以看到全部接口并在线试。主要的：

| 接口 | 作用 |
|---|---|
| `POST /api/exams` | 新建考试（表单上传 paper / sheet / answers 文件；`kind`：exam 考试 / quiz 周测 / homework 平时作业；`structure`：题目结构），后台开始录题和识别版面 |
| `PUT /api/exams/{id}/kind` | 改类型（`{"kind": "homework"}`）；打分和不打分之间改时自动重新批改 |
| `GET /api/exams/{id}` | 考试详情：题目、版面、提示、当前任务 |
| `PUT /api/exams/{id}/questions` | 保存题目、参考答案、评分细则 |
| `POST /api/exams/{id}/objective/solve` | 让 AI 做没有答案的选择、填空题（每题两遍）；`{"redo": true}` 时还没确认的 AI 答案也重做 |
| `POST /api/exams/{id}/layout` | 上传空白答题纸或学生答题纸，重新识别版面 |
| `PUT /api/exams/{id}/template` | 保存修改后的版面区域 |
| `POST /api/exams/{id}/scans` | 上传扫描件并开始批改 |
| `GET /api/jobs/{job_id}` | 查后台任务进度 |
| `GET /api/exams/{id}/results` | 全部成绩和复核状态 |
| `GET /api/exams/{id}/sheets/{sid}` | 一份答卷的裁切图、转写、给分理由 |
| `PUT /api/exams/{id}/sheets/{sid}/q/{题号}/teacher` | 老师改分 / 确认 AI 分数 |
| `POST /api/exams/{id}/sheets/{sid}/merge` | 把另一份答卷（`{"source": "S076"}`，比如补扫的缺页）并进这份 |
| `DELETE /api/exams/{id}/sheets/{sid}` | 删除一份答卷（扫错、重复） |
| `POST /api/exams/{id}/questions/quick` | 按“1-8 单选 5分”这样的题目结构快速添加题目 |
| `POST /api/exams/{id}/answer-sheet` | 按题目生成答题纸（`paper`: A4/A3，`id_digits`，`space`；`heights`: `{"15": 140}` 定某题方框高度（毫米），`null` 恢复自动），并设为版面 |
| `GET /api/exams/{id}/answer-sheet.pdf` | 下载生成的答题纸；加 `?classes=班级id` 是按名单每人一份 |
| `GET/POST/PUT/DELETE /api/rosters…` | 班级名单：列表、导入（粘贴或文件）、修改、删除 |
| `PUT /api/exams/{id}/roster` | 这场考试对照哪几个班的名单 |
| `GET /api/exams/{id}/export.csv` | 导出成绩 |

默认只在本机访问。想让同一局域网的其他电脑用，`python run.py --host 0.0.0.0`（没有登录功能，只在可信的网络里这样做）。

## 代码结构

```
autograde/
  markers.py      定位点检测（“回”字形、实心方块，能处理贴着题框、两个挨着的情况）
  layout.py       版面分析：找封闭题框、纠斜、生成给模型看的编号标注图
  align.py        扫描件对齐（定位点匹配，不够时用 SIFT 特征）、手机照片拉平纸面、对齐质量检查、按原分辨率裁切
  docparse.py     数字版 PDF 的文字层：找题号位置按题切分、读分值、核对模型录入的内容、答题纸题号
  objective.py    选择题选项框和填空横线定位、涂卡识别、填空是否留空、答案写法比对、多选题给分
  exam_setup.py   录题、导入/生成参考答案、识别版面、核对题目与区域
  grading.py      手写转写、按细则给分、结果校验、双评；平时作业判对/半对/错
  pipeline.py     批量流程：对齐分组 → 裁切 → 并发调用模型 → 回写分数
  prompts.py      所有提示词（换学科、调评分口径就改这里）
  llm.py          DeepSeek 接口：重试、JSON 解析（修复 LaTeX 反斜杠）、本地缓存、用量统计
  report.py       成绩汇总、CSV、在答题纸上写分数、缺交名单
  sheetgen.py     按题目生成答题纸：排版、画 PDF、直接生成版面模板；读二维码和涂的学号
  roster.py       班级名单：导入（粘贴/CSV/Excel）、按学号或姓名对答卷、拼音搜索
  server.py       网页后端
static/           网页前端（KaTeX 已放在本地，不依赖外网 CDN）
tests/            模拟 DeepSeek 接口和测试脚本
```

## 已知限制和下一步

- 答题纸版面识别依赖封闭的题框；没有框的区域要手动画。填空题靠横线定位，选择题靠一排排大小相近的选项框定位；定位不到时会把整块区域交给模型识别（会提示）。
- 扫描的答题纸（不是数字版 PDF）没有文字可以读题号，填空横线和选择题按“先行后列”的顺序对应题号，请在版面页看一眼。
- 生成的答题纸里，填空题每题一条横线（一题几个空的，学生写在同一条线上，用分号隔开）；题干不印在答题纸上。
- 学生作答的图片会发送给 DeepSeek 处理。
